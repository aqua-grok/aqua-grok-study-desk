# アクアのGrok勉強デスク♡

資格勉強用の小さな机アプリ。  
時計・試験日カウントダウン・ポモドーロ・今日のタスクを、1画面にまとめました。

Grokと一緒に作った、Python初心者の第17弾です♡

## できること

- デジタル時計
- 試験日カウントダウン（ラベルをクリックして YYYY-MM-DD で登録）
- 残り日数に合わせた短いひとこと
- ポモドーロ（勉強25分 / 休憩5分）
- 今日のタスク（追加・完了・削除）
- 自動保存（`study_desk.txt`）

Sub-Layerの内部ツールではありません。  
公開して使える、勉強机です。

![勉強デスクの全体画面](images/study-desk.png)

- 中：ポモドーロ

- いちばん上に時計
- その下に「試験日 2026-11-15　あと74日」
- 中央にポモドーロ
- 下に今日やること

試験日をまだ入れていなくても、タイマーとタスクだけ使えます。

## 技術スタック

- Python 3.x
- tkinter（標準ライブラリのみ）
- 外部ライブラリなし

## 使い方

1. `study_desk.py` を実行
2. 試験日の文字をクリックして日付を登録
3. 今日のタスクを追加
4. 「開始」でポモドーロを回す

完了したいタスクを選んで「完了」、不要なものは「削除」です。

## カウントダウンのひとこと

- 残り30日超：まだ積める
- 残り8〜30日：弱点を少しずつ潰そう
- 残り7日以内：弱点だけ見よう
- 当日：今日は持っていくものだけ確認

焦らせすぎない言葉にしています。
